# Capsify — website

Static marketing site and privacy policy for the Capsify Android app
(`capsify.outfit.packing.planner`), in the app's eight languages
(en, pt, es, fr, de, it, ru, zh). No build step, no third-party scripts,
fonts or analytics: everything is served from this repository.

- `index.html` — features, widgets, how it works.
- `privacy/` — privacy policy (the URL to give the Play Console).
- `assets/i18n.js` — all copy, one block per language.
- `assets/img/` — screenshots and artwork exported from the app's assets.

Hosted on GitHub Pages from `main`.
